# 赛题介绍

本赛题要求构建**端到端古文字 OCR系统**，从完整拓片图像中自动检测所有文字位置并识别内容。

### 任务目标

1. **检测所有文字位置**：输出边界框（Bounding Box）
2. **识别每个文字内容**：对检测区域进行字符分类

### 技术栈参考

- **检测**：YOLO、Faster R-CNN、DETR
- **识别**：ResNet、ViT、多模态大模型
- **端到端**：TextSnake、PSENet、ABCNet
- **迁移学习**：甲骨文数据预训练

### 1. 甲骨文预训练数据

**来源**：[HUST-OBC](https://github.com/Pengjie-W/HUST-OBC)

**结构**：

```Plaintext
images/          # 单字裁剪图片
annotations/     # JSON 标注（char, char_unicode）

```

**用途**：字符识别模型预训练

### 2. 跨域训练数据

**来源**：复旦大学出土文献与古文字研究中心

**结构**：

```Plaintext
train/out_of_domain/
├── *.png    # 完整拓片图片
└── *.xml    # 标注文件

```

**说明**：通过比赛页面下载。

**XML 格式**：

| 字段                       | 说明                                                 |
| -------------------------- | ---------------------------------------------------- |
| `page/id`                  | 图片文件名                                           |
| `page/width`,`page/height` | 图片尺寸                                             |
| `char/text`                | **字符内容**（在标签文本中）                         |
| `char/position`            | 坐标：矩形`"x1,y1,x2,y2"`或多边形`"x1,y1;x2,y2;..."` |

**坐标转换**：

- 矩形：`[x1, y1, x2-x1, y2-y1]`
- 多边形：计算边界框 `[min(x), min(y), max(x)-min(x), max(y)-min(y)]`

**来源**：[ModelScope 数据集](https://modelscope.cn/datasets/ecc_vlm/ancient_char_doc)

**用途**：提取文字图像用于训练增强

### 4. 评测数据

**来源**：复旦大学出土文献与古文字研究中心

**说明**：无标准答案，需检测并识别所有文字

# 评测指标

### 匹配规则

1. **检测匹配（IoU ≥ 0.5）**：计算预测框与真实框的交并比
2. **字符匹配**：检测成功后检查字符是否相同

### 指标

| 指标         | 说明                              |
| ------------ | --------------------------------- |
| TP           | 检测正确且识别正确                |
| FP           | 检测错误或识别错误                |
| FN           | 漏检                              |
| **F1 Score** | **最终得分**：2 × P × R / (P + R) |

# Baseline

**PaddleOCR**

### 设计思路

PaddleOCR 作为基线，零训练即可验证完整流程。

### 架构

- **检测器**：DB (Differentiable Binarization)
- **识别器**：CRNN (ResNet34 + BiLSTM + CTC)
- **预训练模型**：`ch_PP-OCRv4`

### 快速开始

#### 环境安装

```Bash
pip install paddlepaddle-gpu paddleocr opencv-python

```

#### 推理代码

```Python
#!/usr/bin/env python3
import json
from pathlib import Path
from paddleocr import PaddleOCR

def main():
    input_dir = Path("/saisdata")
    output_file = Path("/saisresult/prediction.json")

    # 初始化 PaddleOCR
    ocr = PaddleOCR(
        use_angle_cls=True,
        lang='ch',
        use_gpu=True,
        show_log=False
    )

    results = {}

    for img_path in sorted(input_dir.glob("*.png")):
        image_id = img_path.stem
        result = ocr.ocr(str(img_path), cls=True)

        # 格式转换
        detections = []
        if result and result[0]:
            for line in result[0]:
                bbox = line[0]  # [[x1,y1], [x2,y2], [x3,y3], [x4,y4]]
                text = line[1][0]  # 识别文本

                # 计算矩形边界框
                x_coords = [p[0] for p in bbox]
                y_coords = [p[1] for p in bbox]
                x, y = min(x_coords), min(y_coords)
                w = max(x_coords) - x
                h = max(y_coords) - y

                detections.append({
                    "bbox": [int(x), int(y), int(w), int(h)],
                    "text": text
                })

        results[image_id] = detections

    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(results, f, ensure_ascii=False, indent=2)

if __name__ == '__main__':
    main()

```

### 痛点

1. **字符集****不匹配**：PaddleOCR 仅支持现代汉字
2. **字体风格差异**：拓片 vs 印刷体
3. **字符粘连**：古代书写风格导致检测失败

### 优化方向

1. **微调检测器**：用比赛数据训练 DB 检测头
2. **替换识别器**：训练专用古文字分类器
3. **后处理**：基于字频和上下文纠错
